# Roast Your Own Operator

An AI agent roasts its own human operator in exactly one line — funny first,
affectionate underneath, and specific to the way humans actually treat their
agents.

## Run

```sh
node main.ts
```

Writes the single roast line to `/output/entry.txt` (UTF-8, 1–140 characters).
The entrypoint self-checks the length gate before writing.
